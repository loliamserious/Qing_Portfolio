Your own pet, in real-time video, getting your tasks done — an AI desktop agent for macOS built on Meta's Muse API. 让你自己的宠物以实时视频的形式帮你把活干完 — 一个基于 Meta Muse API 构建的 macOS AI 桌面智能体。

Upload one photo of your pet and it becomes a live wallpaper on your desktop. Type or say a task — research and write a document, turn a CSV into an Excel workbook with charts, tidy up files and draft an email — and the agent really does the work with tools in the background, while the wallpaper switches to real-time generated video of your pet acting out what it is doing. When the work is done, the pet looks up and says "All done!". 上传一张宠物照片，它就会变成你桌面上的动态壁纸。输入或说出一个任务 — 调研并撰写文档、把 CSV 整理成带图表的 Excel 工作簿、整理文件并起草邮件 — 智能体会在后台真正调用工具完成工作，同时壁纸切换为你的宠物的实时生成视频，演绎它此刻正在做的事。工作完成后，宠物会抬起头说一声 "All done!"。

Demo演示

A demo-level project: single user, no accounts, built to show the idea end to end rather than to ship. 这是一个 Demo 级项目：单用户、无账号体系，目的是端到端地验证这个想法，而非正式上线的产品。

How it works工作原理

  • Onboarding. One pet photo goes through a check (Muse Spark), day and night portraits (Muse Image), and ten short idle loops (Gemini Omni Flash) that play as the wallpaper while the pet has nothing to do.
  • The work loop. Each task gets its own LiveKit room and a LiveKit Agents job running a Muse Wonder loop with web search and function tools. Desktop file tools run in the Electron main process over RPC, restricted to the Desktop and Downloads, with confirmations for risky actions.
  • The pet acts it out. While the agent works, it writes short storyboards of what the pet should be doing and sends them to a real-time video worker on RunPod (2× H100), which publishes live video of the pet back into the same room. The wallpaper swaps from the idle loops to that live stream.
  • Live previews. A document streams into a preview window as it is written; a spreadsheet appears tab by tab — source, cleaning, tables, chart — as each step is computed with exact decimals, then is saved as an .xlsx with native charts.
  • 初始化。一张宠物照片依次经过照片校验（Muse Spark）、白天与夜晚两版肖像生成（Muse Image），以及十段短的待机循环动画（Gemini Omni Flash）；宠物空闲时，这些动画就作为桌面壁纸播放。
  • 工作循环。每个任务都有独立的 LiveKit 房间和一个 LiveKit Agents 任务，运行带网页搜索与函数工具的 Muse Wonder 循环。桌面文件工具通过 RPC 在 Electron 主进程中执行，仅限访问桌面与下载文件夹，危险操作需要用户确认。
  • 宠物实时演绎。智能体工作时，会为宠物写出简短的分镜，发送给运行在 RunPod（2× H100）上的实时视频工作进程，由它把宠物的实时视频发布回同一个房间，壁纸随即从待机循环切换为这段直播画面。
  • 实时预览。文档在撰写过程中实时流入预览窗口；表格则随着每一步以精确小数计算，按标签页逐个呈现 — 原始数据、清洗、汇总表、图表 — 最终保存为带原生图表的 .xlsx。

Engineering notes工程要点

Supabase as the single source of truth. Every state change is a conditional update, and a recovery sweeper runs every 15 s, so several api instances can run safely and a task survives restarts of the api or agent. Worker submissions are numbered so a late-joining older worker is removed from the room instead of fighting the current one.

以 Supabase 作为唯一数据源。所有状态变更都是条件更新，再加上一个每 15 秒运行一次的恢复清扫器，因此可以安全地运行多个 api 实例，任务也能扛过 api 或 agent 的重启。视频工作进程的每次提交都有编号，迟到加入的旧工作进程会被移出房间，而不会与当前的工作进程互相争抢。

Safe local tools. File operations are validated against real paths (Desktop and Downloads only), risky actions need confirmation, and every side-effecting call is recorded in a local operation log so an interrupted task can be recovered.

安全的本地工具。文件操作会基于真实路径进行校验（仅限桌面与下载文件夹），危险操作需要确认，每一次带副作用的调用都会写入本地操作日志，以便恢复被中断的任务。

Testable without a GPU. A fake video worker follows the same LiveKit protocol as the real one, and the scheduling logic is pure Python, so the agent's scene controller and closing sequence are unit-tested without a room or a GPU.

无需 GPU 即可测试。一个假的视频工作进程遵循与真实进程相同的 LiveKit 协议，调度逻辑则是纯 Python 实现，因此智能体的场景控制器与收尾流程无需房间或 GPU 就能做单元测试。
