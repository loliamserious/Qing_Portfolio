# Qing_Portfolio


### LuckyCity AI — Personalized City Recommendation Web App

It suggests the top 5 cities for a user to live in based on their birthday and chosen country.
It integrates a lightweight AI agent that combines demographic analysis with real-time city data to deliver tailored recommendations.

Tech Highlights:

AI Integration: DeepSeek api for reasoning over public city datasets.

Full Stack: React + TypeScript frontend, Python + FastAPI backend, PostgreSQL DB.

Security: bcrypt password hashing + JWT authentication.

Deployment: Cost-efficient cloud hosting on Railway (backend + DB) and Vercel (frontend).

Repos: [UI](https://github.com/loliamserious/LuckyCityUI) [Backend](https://github.com/loliamserious/LuckyCityAPI)

Live Web: https://lucky-city-ui.vercel.app/
